Einrichtung

Einmalig – danach brauchen beide nur noch den Link und die PIN. Alle Eingaben bleiben in diesem Browser; nichts geht an einen fremden Server.

1 Privates Repository für die Daten anlegen

  1. Repository anlegen – Name firmen-aufgaben-data, Sichtbarkeit Private.
  2. Häkchen bei „Add a README file" setzen, damit das Repository nicht leer ist.
  3. Auf Create repository klicken.

In diesem Repository liegt später die Datei board.json – das ist die Datenbank der Pinnwand.

2 Zugangs-Token erzeugen

  1. Fine-grained Token anlegen.
  2. Token name: firmen-aufgaben
  3. Expiration: möglichst lang (z. B. 1 Jahr oder No expiration).
  4. Repository access: Only select repositories → nur firmen-aufgaben-data auswählen.
  5. Permissions → Repository permissions → Contents: auf Read and write stellen.
  6. Generate token klicken und den Token (github_pat_…) kopieren.

Der Token darf ausschließlich auf dieses eine Repository zugreifen – mehr Rechte braucht die Pinnwand nicht.

3 Zugang erzeugen

Fertig. Diesen Link an beide Personen schicken:

Pinnwand öffnen

Der Link enthält den verschlüsselten Zugang. Ohne die PIN ist er wertlos – schicke PIN und Link deshalb am besten getrennt (z. B. Link per E-Mail, PIN per Telefon). Nach dem ersten Öffnen merkt sich der Browser den Zugang; danach genügt die normale Adresse.
